## Контрольные вопросы

1. **Способы установки PHP** 

    Существует несколько основных подходов к установке PHP, и выбор зависит от целей разработки, операционной системы и требований к окружению.

    **Установка PHP как отдельного интерпретатора**

    PHP можно установить напрямую с официального сайта как самостоятельный интерпретатор. Такой способ подходит, если требуется запуск скриптов через командную строку (CLI) или использование встроенного веб-сервера (php -S localhost:8000).

    Данный вариант удобен для учебных задач, тестирования отдельных скриптов и разработки небольших проектов без необходимости установки полноценного веб-сервера.

    **Установка через серверный стек (готовые сборки)**

    Более распространённый способ — использование готовых серверных сборок, которые включают в себя Apache, PHP и систему управления базами данных.

    Наиболее популярные решения:

    * XAMPP

    * WampServer

    * MAMP

    Такие пакеты позволяют быстро развернуть полноценную локальную среду разработки. Они особенно удобны для выполнения лабораторных работ, изучения серверной разработки и тестирования веб-приложений.

    **Установка через менеджеры пакетов (Linux и macOS)**

    В операционных системах Linux и macOS PHP можно установить через системные менеджеры пакетов.

    Например, в Ubuntu используется команда:
    ```
    sudo apt install php
    ```
    В macOS при использовании Homebrew:
    ```
    brew install php
    ```

    Этот способ обеспечивает корректную интеграцию PHP в систему и удобен для разработчиков, работающих в Unix-подобной среде.

    **Использование контейнеризации**

    В профессиональной разработке часто применяется контейнеризация с использованием Docker.

    Этот метод позволяет запускать PHP в изолированной среде без установки в основную систему. Контейнеры обеспечивают переносимость проекта и одинаковое окружение на разных устройствах, что особенно важно при командной разработке.

2. **Как проверить, что PHP установлен и работает?**

    **Проверка через командную строку**

    Самый простой способ — выполнить команду:

    ```
    php -v
    ```

    Если PHP установлен правильно, система отобразит информацию о версии интерпретатора и его конфигурации.

    **Проверка через веб-сервер**

    Для проверки работы PHP в связке с веб-сервером создаётся файл, например info.php, со следующим содержимым:

    ```php
    <?php
    phpinfo();
    ```
    После запуска встроенного сервера PHP или Apache (например, через XAMPP) необходимо открыть файл в браузере.

    Если отображается страница с подробной информацией о конфигурации PHP (версии, модули, параметры сервера), это подтверждает, что PHP корректно установлен и интегрирован с веб-сервером.

    Таким образом, проверка установки PHP может выполняться как на уровне командной строки, так и на уровне веб-сервера, что позволяет убедиться в полной работоспособности среды разработки.

3. **Чем отличается оператор echo от print?**

    Операторы echo и print используются для вывода данных в PHP, однако между ними существуют важные различия.

    **Основные отличия**

    1. Количество аргументов

    * echo может принимать несколько аргументов, разделённых запятой.

    * print может принимать только один аргумент. Попытка передать несколько вызовет синтаксическую ошибку.

    2. Возвращаемое значение

    * echo не возвращает никакого значения.

    * print всегда возвращает целочисленное значение 1, поэтому его можно использовать в выражениях.

    3. Скорость работы

    * echo работает немного быстрее.

    * print работает немного медленнее.

    4. Использование скобок

    * Оба оператора можно использовать как со скобками, так и без них.

    * Принципиальная разница

    5. Ключевыми различиями являются:

    * возможность передачи нескольких аргументов (только у echo);

    * наличие возвращаемого значения (только у print).

    Именно из-за отсутствия возвращаемого значения echo нельзя использовать в выражениях присваивания, тогда как print можно.

    **Итоговый вывод**

    В большинстве случаев на практике используется echo, так как он быстрее и гибче (поддерживает несколько аргументов).
    print применяется реже — в ситуациях, когда требуется вернуть значение 1 в рамках выражения.
